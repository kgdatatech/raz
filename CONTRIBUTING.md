# Contributing to RAZ

Thank you for helping improve Raziel (RAZ).

## Before opening a pull request

1. Open an issue or describe the problem the change addresses.
2. Keep the change focused and include tests for new behavior.
3. Run `npm test`, `npm run lint`, `npx tsc --noEmit`, and `npm run build`.
4. Complete the checklist in the pull-request template.
